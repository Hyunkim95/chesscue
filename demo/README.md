# Submission demo fixture

`chesscue-demo.pgn` is a short completed standard game for quickly demonstrating imported evidence without using personal data.

1. Open **Bring games**.
2. Choose the PGN file or paste its contents.
3. Select **I played White**.
4. Import the game.
5. Open **Training plan**, then **Analyze latest game**.

The fixture intentionally contains a decisive one-move threat. It is synthetic demonstration data, not evidence from a real player.
